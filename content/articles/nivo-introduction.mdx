# Data Visualization with Nivo: Exploring the Cosmos

[Nivo](https://nivo.rocks/) is a rich set of data visualization components built on top of D3 and React. Unlike raw D3 (which we covered in our [D3 Introduction](/articles/d3-introduction)), Nivo provides declarative React components that handle the complexity for you.

<Callout type="info">
  **MIT Licensed & Open Source**: Nivo is fully open source with 13.9k+ GitHub stars. Check out the [source code](https://github.com/plouc/nivo).
</Callout>

Let's explore space data through various chart types!

---

## 1. Bar Chart: Exoplanet Discoveries by Method

How do astronomers find planets around distant stars? Different detection methods have varying success rates.

<Nivo
  type="bar"
  title="Exoplanet Detection Methods"
  height={400}
  colors="cosmic"
  data={[
    { method: 'Transit', count: 4142, pct: 76 },
    { method: 'Radial Velocity', count: 1052, pct: 19 },
    { method: 'Direct Imaging', count: 67, pct: 1.2 },
    { method: 'Microlensing', count: 209, pct: 3.8 },
    { method: 'Timing', count: 32, pct: 0.6 },
    { method: 'Astrometry', count: 3, pct: 0.05 },
  ]}
  keys={['count']}
  indexBy="method"
  margin={{ top: 50, right: 130, bottom: 50, left: 120 }}
  padding={0.3}
  layout="horizontal"
  valueScale={{ type: 'linear' }}
  indexScale={{ type: 'band', round: true }}
  borderRadius={4}
  borderWidth={1}
  borderColor={{ from: 'color', modifiers: [['darker', 1.6]] }}
  axisTop={null}
  axisRight={null}
  axisBottom={{
    tickSize: 5,
    tickPadding: 5,
    tickRotation: 0,
    legend: 'Confirmed Exoplanets',
    legendPosition: 'middle',
    legendOffset: 40
  }}
  axisLeft={{
    tickSize: 5,
    tickPadding: 5,
    tickRotation: 0,
  }}
  labelSkipWidth={12}
  labelSkipHeight={12}
  labelTextColor={{ from: 'color', modifiers: [['darker', 3]] }}
  legends={[
    {
      dataFrom: 'keys',
      anchor: 'bottom-right',
      direction: 'column',
      translateX: 120,
      itemWidth: 100,
      itemHeight: 20,
      itemTextColor: '#cbd5e1',
      symbolSize: 12,
      symbolShape: 'circle',
    }
  ]}
/>

The **Transit method** dominates thanks to missions like Kepler and TESS, which watch for the tiny dimming when a planet crosses in front of its star.

## Supported Chart Types

The `<Nivo>` component supports all major Nivo chart types:

| Type | Description |
|------|-------------|
| `bar` | Vertical/horizontal bar charts, grouped or stacked |
| `line` | Line charts with optional areas |
| `pie` | Pie and donut charts |
| `radar` | Radar/spider charts |
| `scatterplot` | Scatter plots |
| `heatmap` | Heat maps |
| `stream` | Stacked area/stream graphs |
| `bump` | Bump charts for rankings |
| `areabump` | Area bump charts |
| `chord` | Chord diagrams |
| `funnel` | Funnel charts |
| `treemap` | Tree maps |
| `sunburst` | Sunburst charts |
| `sankey` | Sankey diagrams |
| `network` | Network graphs |
| `swarmplot` | Swarm plots |
| `waffle` | Waffle charts |
| `calendar` | Calendar heatmaps |
| `marimekko` | Marimekko charts |
| `radialbar` | Radial bar charts |
| `circlepacking` | Circle packing |
| `bullet` | Bullet charts |

## Color Schemes

Built-in color schemes optimized for our dark theme:

- `cosmic` - Default cyan/purple/amber palette
- `nebula` - Vibrant pinks and purples
- `deepspace` - Dark blues and purples
- `solar` - Yellows to deep reds
- `aurora` - Teals and cyans
- `stellar` - Warm yellows and ambers

Or pass a custom array: `colors={['#ff6b6b', '#4ecdc4', '#45b7d1']}`
