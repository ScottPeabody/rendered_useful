I built **rendered_useful** as a modern, open-source portfolio and article platform. The goal was to create something that looks great, performs well, and can serve as a starting point for a new a collaborative builder community.

## Why I Built This

I wanted a place to share my projects, experiments, and learnings. Most portfolio templates felt either too minimal or too bloated. I wanted something with a modern design, great developer experience, and the ability to write rich, interactive content. My hopes is that this grows into a community-driven platform for everyone to make whatever things they want and to showcase their work.

<Callout type="info" title="Open Source">
  This site is a work in progress and will change a lot over time. I will post new articles, projects and features as I build them.
</Callout>

## Tech Stack

The site is built with a modern React stack focused on developer experience and performance:

- **React 18+** - The foundation, with lazy loading and Suspense
- **TypeScript** - Type safety throughout
- **Vite** - Lightning fast development and builds
- **Tailwind CSS v4** - Modern utility-first styling with CSS variables
- **Framer Motion** - Smooth animations and page transitions
- **MDX** - Write content with embedded React components

## Design Decisions

The design follows a "dark mode first" philosophy with glass morphism effects. I used CSS custom properties for theming, which makes it easy to switch between dark and light modes. This will probably change and evolve as I learn and get feedback.

```css
/* Dark mode colors */
--color-background: #0a0a0f;
--color-surface: #12121a;
--color-accent-primary: #6366f1;
--color-accent-secondary: #8b5cf6;

/* Glass morphism */
--color-glass: rgba(255, 255, 255, 0.05);
--color-glass-border: rgba(255, 255, 255, 0.1);
```

### Rust

```rust
use std::collections::HashMap;

fn main() {
    let mut scores: HashMap<String, i32> = HashMap::new();
    scores.insert(String::from("Blue"), 10);
    scores.insert(String::from("Red"), 50);
    
    for (key, value) in &scores {
        println!("{}: {}", key, value);
    }
}
```

