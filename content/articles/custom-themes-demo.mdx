## Available Themes

We currently have these theme presets:

- **cyberpunk** - Neon pink and cyan on dark purple
- **terminal** - Classic green-on-black hacker aesthetic
- **retro** - Warm oranges and browns, vintage feel
- **ocean** - Deep sea blues and teals
- **paper** - Clean light mode for comfortable reading
- **sunset** - Warm pinks and oranges gradient

## How It Works

In your MDX frontmatter, just add:

```yaml
---
theme: "cyberpunk"
---
```

The theme system:
1. Reads the theme name from frontmatter
2. Looks up the preset's CSS variables
3. Applies them to the document root
4. Automatically restores the original theme when you leave the page

## Technical Details

Themes override CSS custom properties:

```css
--color-background
--color-surface
--color-text-primary
--color-accent-primary
--font-display
/* ... and more */
```

The `useArticleTheme` hook handles applying and cleaning up theme variables, ensuring the site returns to normal when you navigate away.

## Future Plans

Currently, themes are **page-scoped** - they only apply while you're on this article and reset when you navigate away. This is intentional for now.

We're exploring a more comprehensive theming system:

- **Global user preference** - Let users pick a preferred theme from their settings
- **Per-page overrides** - Authors can still customize individual articles/projects
- **Override permissions** - Users could choose whether to allow page-specific themes or stick with their preference
- **Transition animations** - Smooth visual transitions when themes change

The goal is to balance author creativity with user control - letting writers create immersive themed experiences while respecting reader preferences.
