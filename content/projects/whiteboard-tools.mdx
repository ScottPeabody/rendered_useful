# Whiteboard Tools

Add hand-drawn diagrams, flowcharts, and sketches directly to your MDX articles. This project integrates two powerful open-source whiteboards that run entirely in the browser.

---

[Excalidraw](https://excalidraw.com) provides a hand-drawn, sketchy aesthetic perfect for diagrams and wireframes.

## How to Use in Your Articles

### Available Props

Both editors support these common props:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `height` | number | 500 | Height in pixels |
| `viewOnly` | boolean | false | Read-only mode (no editing) |
| `dataUrl` | string | - | URL to load diagram JSON from |
| `initialData` | object | - | Inline JSON data |
| `showSave` | boolean | true | Show the Save File button |
| `showClear` | boolean | true | Show the Clear button |

**Excalidraw-specific:**
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `storageKey` | string | - | Key for localStorage auto-save |
| `theme` | 'light' \| 'dark' | 'dark' | Color theme |
| `gridMode` | boolean | false | Show grid background |

**tldraw-specific:**
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `persistenceKey` | string | - | Key for localStorage auto-save |

---

### Loading Diagrams

There are three ways to display a diagram:

#### 1. From a URL (Recommended for sharing)

Host your JSON file anywhere accessible via URL—GitHub raw files, your site's `/public` folder, or any CDN:

```jsx
{/* From your site's public folder */}
<ExcalidrawEditor 
  viewOnly={true}
  dataUrl="/examples/my-diagram.json"
/>

{/* From GitHub raw content */}
<TldrawEditor 
  viewOnly={true}
  dataUrl="https://raw.githubusercontent.com/user/repo/main/diagram.json"
/>
```

#### 2. Inline JSON (For small diagrams)

Pass the data directly via the `initialData` prop. This works well for simple diagrams:

```jsx
<ExcalidrawEditor 
  viewOnly={true}
  initialData={[
    {
      "type": "rectangle",
      "x": 100,
      "y": 100,
      "width": 200,
      "height": 100,
      "strokeColor": "#1e1e1e",
      "backgroundColor": "#a5d8ff"
    }
  ]}
/>
```

#### 3. Interactive with Auto-Save

For editable canvases, use `storageKey` (Excalidraw) or `persistenceKey` (tldraw) to enable localStorage persistence:

```jsx
{/* User's work persists in their browser */}
<ExcalidrawEditor storageKey="my-article-sketch" />
<TldrawEditor persistenceKey="my-tldraw-canvas" />
```

---

### Customizing the Toolbar

Hide buttons for cleaner embeds:

```jsx
{/* Read-only with no toolbar */}
<ExcalidrawEditor viewOnly={true} dataUrl="/examples/flow.json" />

{/* Editable but no Save/Clear buttons */}
<ExcalidrawEditor 
  storageKey="hidden-toolbar" 
  showSave={false} 
  showClear={false} 
/>

{/* Only show Save */}
<TldrawEditor persistenceKey="save-only" showClear={false} />
```

---

### Creating Diagrams

1. Draw your diagram in an **Interactive Canvas** above
2. Click **💾 Save File** to download the JSON
3. Host the file (see options below)
4. Embed with `dataUrl` or `initialData`

**Hosting options:**
- `/public/examples/` in this repo → deployed to GitHub Pages
- GitHub Gist → use raw URL
- Any static file host or CDN
