# But Can It Run DOOM?

The eternal question for any new technology. And the answer is: **yes**.

This is the original 1993 DOOM shareware running entirely in your browser via DOSBox compiled to WebAssembly. No plugins, no downloads, no installation.

## How It Works

1. **js-dos v8** - DOSBox compiled to WebAssembly, loaded from CDN
2. **DosRunner Component** - A generic React component for running any DOS game
3. **DOOM Shareware Bundle** - Pre-configured `.jsdos` bundle with autostart
4. **Your Browser** - Running a 1993 DOS game in 2026

The entire DOS environment runs client-side. Your browser is now a 486.

## Why DOOM?

DOOM (1993) by id Software is one of the most influential games ever made. It popularized the first-person shooter genre and was technically groundbreaking for its time.

The "Can it run DOOM?" meme exists because:
- DOOM has been ported to everything (calculators, ATMs, pregnancy tests, thermostats)
- It represents a baseline test for any computing platform
- The source code was released in 1997, enabling endless ports

## Technical Notes

- Uses js-dos v8 loaded dynamically from CDN
- Game bundle (`.jsdos`) hosted locally in `/public/games/`
- `autoStart: true` bypasses the js-dos login/save screen
- Runs the shareware version (Episode 1: Knee-Deep in the Dead)
- Full game would require owning the WAD files
- Audio may require user interaction to start (browser autoplay policy)
- Fullscreen supported via container element (not iframe)

## The Shareware Legacy

In 1993, id Software distributed DOOM as shareware - the first episode was free, and you could buy the full game if you liked it. This distribution model helped DOOM become a phenomenon.

The shareware version is still legally free to distribute, which is why we can run it here.
