# The Shrine

The pixel-wizard space runs the `terminal` theme, green on black. This page overrides it with `retro`, and hides the site footer via frontmatter (`hideFooter: true`). Same alias, different room.

## The canon

1. **Tetris**: the perfect game. No story, no graphics to date it, no fat to trim.
2. **Prince of Persia**: rotoscoped animation that still moves better than most modern platformers.
3. **SimCity 2000**: the game that taught a generation what an isometric grid was.

<Callout type="warning" title="Hot take">
  Every "juice" tutorial (screen shake, particles, tweens) is rediscovering what 1985 arcade games did in 8 KB.
</Callout>

## Why a shrine page

Aliases exist so one person can be multiple publishers. Pages exist so each publisher can have rooms. This is the back room with the good posters.
